# More FAQs

## Is there a way, in the UI, for me to see in which ER Diagrams a specific table can be found?

You can easily do this from the Object Browser.  Type the table name in the search bar at the top of the pane: the tree is filtered to show only the matching entity, together with all the Diagram Views in which this entity appears.\
\
More details on the Object Browser search here: [https://hackolade.com/help/Objectbrowserpane.html](https://hackolade.com/help/Objectbrowserpane.html)
