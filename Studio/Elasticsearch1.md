# Elasticsearch mappings

Elasticsearch mappings are dynamically generated as you create your schema.

The script can also be exported to the file system via the menu Tools > Forward-Engineering, or via the [Command-Line Interface](CommandLineInterface.md).

![Elasticsearch forward-engineering mappings](<lib/Elasticsearch forward-engineering mappings.png>)

With the Elasticsearch v7 and above plugin, you can also write your own custom script format, besides the Kibana Script and CURL Script formats, as described in [Elasticsearch custom script formats](Elasticsearchcustomscriptformats.md).
