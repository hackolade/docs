# Model Hub configuration

After the server is running, open the Model HUB in a browser. You may be redirected to the license screen in the Admin panel first. You will need to enter the license key provided to you.

&nbsp;

Once that is done, you can configure in the admin panel the following:

[](</o/HBtg1gLTy0nw4NaX0MaV/s/k3cNzEeXGnIxGNnOQdDa/hub/installation-guide/configuring-the-hub/authentication>)

[Authentication](<Authentication1.md>):&nbsp; sign in with your identity provider (recommended before exposing the instance)

[Git providers webhooks](<Gitrepoconfiguration.md>): connect repositories so models sync into the Model HUB

[MCP server](<MCPserver.md>): optional AI-assistant integration (extra IdP redirect URIs when auth is enabled)

&nbsp;

When you are ready for users, complete license validation as prompted in the UI.
